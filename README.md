# Exercícios de Python: Funções e Módulos

Repositório com as resoluções dos exercícios práticos sobre funções, escopo de variáveis e utilização do módulo `math`.

---

## 📌 Descrição dos Exercícios

### 🟢 Exercício 1: Arredondamento e Raiz Quadrada (`ex01.py`)
Calcula a raiz quadrada e os arredondamentos para cima (`math.ceil`) e para baixo (`math.floor`) de um número decimal digitado pelo usuário.

### 🟢 Exercício 2: Calculadora de Área de Círculo (`ex02.py`)
Contém a função `calcular_area_circulo(raio)` que calcula e retorna a área de um círculo utilizando a constante `math.pi`, formatando a saída com 2 casas decimais.

### 🟢 Exercício 3: Parâmetros e Condicionais - Maior de Três (`ex03.py`)
Implementa a função `encontrar_maior(a, b, c)` que recebe três números inteiros e determina qual deles é o maior valor.

### 🟢 Exercício 4: Compreendendo Escopo de Variáveis (`ex04.py`)
Demonstra a diferença prática entre **escopo local** e **escopo global**, explicando por que a alteração de uma variável dentro de uma função não afeta a variável externa.

### 🟢 Exercício 5: Desafio Integrador - Cálculo de Hipotenusa (`ex05.py`)
Aplica a estrutura recomendada de organização em Python (1. Imports, 2. Funções, 3. Código Principal) para calcular a hipotenusa de um triângulo retângulo usando o Teorema de Pitágoras ($h = \sqrt{a^2 + b^2}$).
